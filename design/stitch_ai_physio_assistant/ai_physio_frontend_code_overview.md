The frontend code for AI Physio is provided in the individual screens generated for the Auth Portal, Patient Dashboard, Live AI Session, Progress Analytics, Physiotherapist Dashboard, Administrator Dashboard, Session Reports, and Notifications Panel.

Each screen is built using a modern tech stack:
- **HTML5**: For semantic structure.
- **Tailwind CSS**: For utility-first styling, ensuring a responsive and consistent dark theme.
- **Inter Font**: Applied via the design system for professional legibility.
- **Lucide Icons / Material Icons**: For intuitive navigation and action signals.

The code follows the "Aetheris Health" design system tokens, maintaining a dark slate background (#051424) with teal (#14b8a6) accents.

To access the source code for any specific screen, you can inspect the individual artifacts provided in the project.
